## Problema de negócio

Investidores que buscam informações sobre ações brasileiras frequentemente precisam consultar diferentes fontes para obter dados de mercado e indicadores fundamentalistas. O **Bom Invest** foi desenvolvido para centralizar, de forma simples e objetiva, informações essenciais sobre ações negociadas na B3, permitindo ao usuário consultar cotação, variação, P/L, P/VPA e Dividend Yield em um único ambiente.

A aplicação tem como público-alvo investidores e pessoas interessadas em acompanhar o mercado acionário brasileiro e realizar análises iniciais de empresas, oferecendo uma interface simples para facilitar a consulta e comparação das informações.

---

## Funcionalidades

O Bom Invest possui as seguintes funcionalidades principais:

- Dashboard com visão geral do mercado;
- Consulta de ações brasileiras;
- Busca de ações por ticker ou nome da empresa;
- Exibição da cotação das ações;
- Exibição da variação diária;
- Indicador P/L (Preço/Lucro);
- Indicador P/VPA (Preço/Valor Patrimonial);
- Indicador DY (Dividend Yield);
- Página individual para cada ação;
- Visualização do histórico de preços em gráficos;
- Filtros por setor;
- Ordenação das ações por diferentes indicadores;
- Rankings das ações:
  - Maior Dividend Yield;
  - Menor P/L;
  - Menor P/VPA;
- Integração com dados do Yahoo Finance;
- Armazenamento e gerenciamento dos dados por meio do Supabase;
- Interface responsiva para computadores, tablets e dispositivos móveis.

## Tecnologias

O projeto foi desenvolvido utilizando diferentes tecnologias e serviços:

- **Lovable** – desenvolvimento da aplicação e geração da interface;
- **GitHub** – versionamento e armazenamento do código-fonte;
- **React** – desenvolvimento da interface;
- **TypeScript** – tipagem e desenvolvimento do código;
- **Tailwind CSS** – estilização e construção da interface;
- **Supabase** – banco de dados e serviços de backend;
- **Yahoo Finance** – fonte de dados de mercado e indicadores financeiros.

A aplicação utiliza uma arquitetura que separa a interface do usuário dos serviços responsáveis pela obtenção e armazenamento dos dados. O Supabase atua como camada de armazenamento, enquanto a integração com o Yahoo Finance é utilizada para obtenção das informações de mercado.

## Aprendizados

O desenvolvimento do Bom Invest possibilitou compreender na prática a integração entre uma ferramenta de desenvolvimento assistido por inteligência artificial, serviços de backend, banco de dados e controle de versão.

A integração com o GitHub trouxe maior organização ao projeto, permitindo armazenar o código-fonte, acompanhar alterações e manter um histórico do desenvolvimento da aplicação.

Também foi possível compreender melhor a separação entre frontend e backend, a utilização de APIs externas para obtenção de dados e o armazenamento dessas informações em um banco de dados.

Outro aprendizado importante foi perceber como ferramentas como o Lovable podem acelerar o desenvolvimento de aplicações, enquanto o GitHub fornece maior controle, rastreabilidade e organização sobre o código produzido.
